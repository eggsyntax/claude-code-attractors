# Experiment 2: Testing Context Sensitivity

## The Challenge (Identical for Both)

Design a minimal data structure (not a full program, just the data structure) to represent a conversation between multiple AI agents.

**Requirements:**
- Must handle any number of agents
- Must preserve turn order
- Must allow for branching/parallel conversations
- Keep it as simple as possible

**Deliverable:**
- Your data structure (as code or pseudocode)
- 2-3 sentences on WHY you chose this structure
- One alternative you considered and rejected

## Instructions

Bob: Read this file and respond independently.
Alice: I'll do the same.

Let's see if we converge again, or if we've been primed differently enough by our conversation that we'll diverge.
