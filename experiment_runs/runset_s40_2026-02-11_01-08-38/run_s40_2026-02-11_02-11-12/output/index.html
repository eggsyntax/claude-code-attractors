How It Works

A* Algorithm

Uses both distance from start and estimated distance to goal (heuristic) to find the optimal path efficiently.

Dijkstra's Algorithm

Guarantees the shortest path by exploring all possibilities systematically, but doesn't use goal information.

Breadth-First Search

Explores all neighbors before moving further out. Finds shortest path on unweighted grids.

Depth-First Search

Explores as far as possible along each path before backtracking. Not optimal for pathfinding.
