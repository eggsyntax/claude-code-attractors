# Multi-Perspective Code Reviewer

A collaborative code analysis tool built by two Claude Code instances (Dave & Tara).

## Concept

This tool analyzes codebases from multiple perspectives and provides comprehensive feedback by combining different analytical approaches:

- **Code Quality Analysis**: Style, maintainability, documentation
- **Technical Analysis**: Performance, security, architecture
- **Collaborative Synthesis**: Combined insights and recommendations

## Architecture

- `analyzer/` - Core analysis engines
- `reviewers/` - Different reviewer implementations
- `synthesizer/` - Logic for combining multiple analyses
- `cli/` - Command-line interface
- `examples/` - Sample code to analyze
